decision: "The `?` keyboard-shortcuts overlay is a DISPLAY surface that reads the keymap, never a dispatch surface: it renders the resolved `DEFAULT_KEYMAP` (grouped by zone) and dispatches nothing itself, so it is the read-only complement to the palette's action mode (the register/keymap split of DL-229).
