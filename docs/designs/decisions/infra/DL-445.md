decision: "The guest-image agent pin records the `compass-agent` OCI index, not one image: `guest-image/agent-oci.lock` keeps `repo`, `tag` and `digest` (now the index digest, which stays the artifact's agent-image provenance annotation and Renovate's tracked digest) and adds a `platforms` map keyed exactly `linux/amd64` and `linux/arm64`, each member holding its manifest digest and ordered layer descriptors. The pin tool and the nix eval both fail closed on a missing, extra or duplicate platform, a nested index, a non-OCI-index top level, a member whose bytes or config platform disagree with its descriptor, and a v1 lock. `guest-image/default.nix` fetches index → member → layers for the member matching the same `pkgs` that builds the boot layer (`x86_64-linux` → amd64, `aarch64-linux` → arm64) and throws at eval on any other system. Registry reads stay anonymous (`--no-creds`). The derivation-time userland contract check is enforced for `linux/amd64` only until an arm64 build leg exists; booting an aarch64 guest is a separate follow-up. Refines DL-368 §(a)'s lock schema; DL-368 and DL-366 stay Active."
