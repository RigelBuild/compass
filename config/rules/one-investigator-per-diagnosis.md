# One investigator per shared failure

When multiple agents encounter the same shared failure, one agent owns the
diagnosis. Route evidence to that owner and stop parallel investigations; do not
produce competing fixes for a shared symptom. The owner records the failing
surface, reproduction, and evidence-backed cause, then reports the verified
resolution to affected lanes. Resume independent work while diagnosis proceeds.
