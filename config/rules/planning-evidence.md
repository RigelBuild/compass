# Planning evidence

When an artifact makes a claim about external code, ground every claim in a source read during the current session. See `evidence-and-safe-tool-args` for citation and quoted-evidence requirements; cite code by symbol and repository-relative path, never `path:line`, and quote the snippet that supports the claim.

Before prescribing a check, run it against a known-healthy subject and confirm it stays quiet. A check exercised only on a broken subject does not show that it distinguishes the fault from healthy cases.
