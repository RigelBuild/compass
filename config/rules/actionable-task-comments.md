# Comments for deferred work

Do not put session findings, status, or planning metadata in source comments.
A `TODO`, `FIXME`, or equivalent may describe deferred work, a known limitation,
or a temporary workaround. Include a tracker reference only when it owns that
work, name its current owner, and leave enough context for the comment to stand
alone.
